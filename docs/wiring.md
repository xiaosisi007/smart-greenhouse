> 强电（电机/接触器）务必由持证电工施工。本文给出弱电控制与强电控制回路的对接方式。

## 三、控制回路（关键）

```
ESP32 GPIO ──→ 继电器 ──→ 接触器线圈(A1/A2) ──→ 接触器主触点 ──→ 电机绕组
                                  │
                          【机械互锁】正转接触器 与 反转接触器 互锁
                                  │
限位开关 ── 串入接触器线圈回路（硬件级到位断电）+ ESP32 读取（软件级停机）双保险
本地手动按钮 ── 与继电器输出并联（断网/MCU 故障时人工可控）
```

要点：
1. **互锁必装**：卷帘正/反两个接触器、风口开/关两个接触器，分别机械互锁，杜绝同时吸合短路烧电机。
2. **限位双保险**：限位开关既串进接触器线圈回路（硬件到位即断电），又接 ESP32（软件 `actuatorSafety` 到位停）。
3. **过流保护**：ACS712 接 ESP32 ADC，运行电流超阈值（`CURTAIN_OVERCURRENT_A` / `VENT_OVERCURRENT_A`）判故障停机并告警，需远程或手动复位。
4. **断网兜底**：固件 `localFallback()` 在 MQTT 断开时按本地阈值自动控温/卷帘。
5. **急停**：急停按钮直接切断接触器线圈电源，优先级最高。

## 四、继电器电平

模组若为「低电平触发」（常见），保持 `pins.h` 中 `RELAY_ACTIVE_LOW 1`；高电平触发改为 `0`。

## 五、电流标定

ACS712-20A 灵敏度约 100mV/A、偏置 2.5V。`readCurrent()` 为简化算法，现场应空载测偏置电压并按实际灵敏度校正，必要时多次采样取 RMS。

# 强电主回路方案（220V 单相 / 380V 三相）

## 现场电压自检与选型流程（每个棚部署前先做）

同一套控制箱弱电部分（ESP32/继电器/传感器/固件）对两种电压**完全通用**，部署时只需按下面流程确定强电方案：

1. **看进线**：
   - 两根线（火+零，相对零 ~220V）→ 单相 220V → 走 **方案 A**
   - 三根相线 + 零线（相间 ~380V，相对零 ~220V）→ 三相四线 → 走 **方案 B**，控制电直接取「任一相+零」220V
   - 只有三根相线无零线（相间 ~380V）→ 三相三线 → 走 **方案 B + 第八节 JBK 变压器**给控制电降压
2. **看电机铭牌**：电机电压必须与主回路一致（220V 单相电机配方案 A；380V 三相电机配方案 B）。订卷帘机/卷膜器时**按现场电压订货**，不要现场转压。
3. **按电机铭牌电流**查第九节选型表，确定断路器/接触器/热继电器/线径。
4. **接触器线圈统一选 AC220V**：方案 A 取火+零；三相四线取相+零；三相三线取 JBK 变压器 220V 输出。这样同一张弱电接线图三种现场通用。

| 现场 | 主回路 | 控制电 220V 来源 | 额外部件 |
|---|---|---|---|
| 220V 单相 | 方案 A | 火 + 零 | 漏保必装 |
| 380V 三相四线 | 方案 B | 任一相 + 零 | 缺相/相序保护 |
| 380V 三相三线 | 方案 B | JBK 变压器(380→220) | 缺相/相序保护 + JBK3-250/400VA |

> 混合现场（部分棚 220V、部分棚 380V）：控制箱弱电部分批量做成一样的，仅强电柜按上表分两种配置；固件 `config.h` 里的过流阈值按各自电机额定电流调整（220V 电机同功率电流约为 380V 的 √3 倍）。

> 以下为**强电主回路**部分，务必由持证电工施工。
> **弱电控制部分（ESP32 + 8 路继电器 + SHT31/BH1750 + 限位 + ACS712 + 24V/5V 电源 + 急停 + 本地手动按钮 + IP65 箱）两套方案完全相同**，固件 / 后端 / App **均无需修改**。
> 继电器只用于驱动接触器线圈（弱电），**不直接带电机**；电机由接触器主触点切换。

## 六、方案 A：220V 单相（小功率，常见管状电机 / 卷膜器）

适用：单相 220V、带运行电容、可正反转的电机（通风口、侧窗卷膜、中小卷帘）。功率多为 0.12 ~ 0.75 kW。

| 部件 | 规格 | 数量/电机 | 说明 |
|---|---|---|---|
| 断路器 | 2P，按电流选（见选型表） | 1 | 单相进线 |
| 漏电保护 | 2P 漏保（30mA） | 1 | 潮湿环境必装 |
| 交流接触器 | CJX2 系列，**线圈 AC220V** | 2（正/反） | 切换正反转 |
| 机械互锁 | 接触器机械互锁配件 | 1 | 防正反转同时吸合 |
| 热继电器 | 按电机额定电流整定 | 1 | 过载保护 |

**正反转原理**：单相电机靠切换主 / 副绕组（运行电容）的接入方向实现，两个接触器分别接「正转端子」「反转端子」。

```
L ─┬─[2P 断路器]─[2P 漏保]──┬─[KM1 正转]─┐
   │                        ├─[KM2 反转]─┤→ 单相电机（含运行电容）
N ─┴────────────────────────┴────────────┘
   KM1/KM2 机械互锁 + 线圈回路串限位；线圈 AC220V 取「火+零」
```

## 七、方案 B：380V 三相（大功率，三相异步电机，大棚卷帘主流）

适用：三相 380V 异步电机（大跨度卷帘机、连栋温室卷膜）。功率多 ≥ 0.75 kW。

| 部件 | 规格 | 数量/电机 | 说明 |
|---|---|---|---|
| 断路器 | 3P，按电流选（见选型表） | 1 | 三相进线 |
| 交流接触器 | CJX2 系列，**线圈建议 AC220V** | 2（正/反） | 切换正反转 |
| 互锁 | 机械互锁 **+** 电气互锁（辅助常闭触点串对方线圈） | 1 套 | 三相必须**双重互锁** |
| 热继电器 | 三相热继电器，按电机额定电流整定 | 1 | 过载保护 |
| **相序/缺相保护继电器** | 三相专用（如断相 / 错相保护器） | 1 | **三相必加**，防缺相 / 错相烧电机 |

**正反转原理**：调换三相中任意两相（如 L1↔L2）。正转接触器按 L1-L2-L3 接；反转接触器把其中两相对调；两者机械 + 电气互锁。

```
L1 L2 L3 ─[3P 断路器]─[缺相/相序保护]─┬─[KM1: L1-L2-L3 ]─┐
                                       └─[KM2: L2-L1-L3 ]─┤→ 三相电机 → 热继电器
                                          (两相对调=反转)   │
   KM1/KM2 机械互锁 + 电气互锁（辅助常闭串对方线圈）；线圈 AC220V
```

## 八、推荐方案：380V 三相三线（无零线）+ JBK 控制变压器

> **针对现场为「三相三线、无零线」的场景**（用户实际配电）。结论：**电机用 380V 不转压，只给"弱电 + 控制回路"加一台小变压器降到 220V。**

### 8.1 电机怎么接（不转压）
- **卷帘电机（铭牌标 380/220）**：按**星形 (Y) 接法接 380V 三相**。接线盒里三个绕组尾端短接成中性点，三个首端接 L1/L2/L3。
  - 铭牌「380/220」= Y 接 380V、Δ 接 220V，现场是 380V 三相 → 选 **Y 接**，无需任何转换。
- **卷膜器**：**强烈建议订 380V 三相款**，与卷帘一致直接接，零转换。
  - ⚠️ 若买成 220V 单相卷膜器：因无零线，必须为它单独配一台**按其功率选型的变压器**（功率大则贵且发热），很不划算。订货时直接跟厂家要 **380V 三相**。

### 8.2 控制电为什么要小变压器（唯一需要"转压"处）
ESP32、5V/24V 开关电源、4G 模块、接触器 AC220V 线圈都需要 220V；现场无零线、相间为 380V，普通 220V 开关电源不能直接吃 380V。所以：

- 加一台**机床控制变压器 JBK 系列**：**输入 380V（取两根相线 L1/L2），输出 220V**。
- 容量几百 VA 即可（见 8.4），给全部弱电开关电源 + 所有接触器 220V 线圈供电。
- 接触器统一选 **AC220V 线圈**，全部接到该变压器 220V 输出。
- 这台变压器小而便宜（百元级），是三相无零线场景的标准做法，**不是给电机用的大变压器**。

### 8.3 整体配电结构
```
380V 三相三线进线（L1 L2 L3 + PE 接地，无 N）
 │
 ├─[3P 断路器]─[缺相/相序保护]─→ 卷帘电机(Y 接 380V)
 │      └ KM1/KM2(220V 线圈) 机械+电气互锁 + 热继电器 + 限位串线圈回路
 │
 ├─[3P 断路器]─[缺相/相序保护]─→ 卷膜器(建议 380V 三相)
 │      └ 同上一套
 │
 └─取 L1/L2 两根相线(380V) ─[2P 断路器]─→ JBK 控制变压器 380V→220V
        └ 220V 输出 ──┬─ 弱电开关电源(220V→5V/24V)：ESP32 / 继电器 / 传感器 / 4G
                       └─ 所有接触器 AC220V 线圈

急停按钮：串入变压器 220V 控制回路总线（按下→所有线圈失电→电机停），优先级最高
接地 PE：电机外壳、控制箱、变压器铁芯与屏蔽、传感器屏蔽层 均可靠接地
```

要点：
1. 电机全用 380V，**不转压**；只有控制电用一台 JBK 小变压器降 220V。
2. 三相**必加缺相 / 相序保护继电器**（无零线时缺相更危险）。
3. JBK 变压器输出侧建议加 2P 断路器 / 保险，并与急停回路联动。
4. 弱电控制逻辑、固件、App、后端规则**完全不用改**，仅现场强电接线不同。

### 8.4 JBK 控制变压器容量估算
容量 ≈ 所有接触器线圈**吸合功率之和** + 弱电开关电源功率，并留 2~3 倍余量（接触器吸合瞬时电流大）。

| 负载 | 估算 |
|---|---|
| 单个 CJX2 接触器线圈（吸合） | ≈ 50~70 VA（保持仅几 VA） |
| 4 个接触器同时吸合峰值 | ≈ 200~280 VA |
| 弱电开关电源（ESP32+继电器+传感器+4G） | ≈ 50~100 W |

**推荐：JBK3-250VA**（接触器≤4、负载轻）或 **JBK3-400VA**（接触器多 / 余量足，更稳妥）。

## 九、强电选型对照表（按电机功率取对应行）

> 以 380V 三相电机为例（功率因数 ~0.8、效率 ~0.85 估算额定电流 `I ≈ P / (√3·380·0.8·0.85)`）。**断路器、热继电器整定值、线径以电机实际铭牌电流为准**，下表为常见档位参考，务必现场核对铭牌。

| 电机功率 | 额定电流(约) | 3P 断路器 | 接触器(CJX2) | 热继电器整定 | 主回路铜线 |
|---|---|---|---|---|---|
| 0.75 kW | ~1.8 A | 6 A | CJX2-0910/1210 | 1.5~2.4 A | 1.0 mm² |
| 1.5 kW | ~3.5 A | 10 A | CJX2-0910/1210 | 2.5~4 A | 1.5 mm² |
| 2.2 kW | ~5 A | 10~16 A | CJX2-1210/1810 | 4~6 A | 1.5 mm² |
| 3.0 kW | ~6.8 A | 16 A | CJX2-1810 | 5.5~8 A | 2.5 mm² |
| 4.0 kW | ~9 A | 20 A | CJX2-2510 | 7~10 A | 2.5 mm² |
| 5.5 kW | ~12 A | 25 A | CJX2-2510/3210 | 9~13 A | 4 mm² |
| 7.5 kW | ~16 A | 32 A | CJX2-3210 | 12~18 A | 4~6 mm² |

220V 单相电机额定电流约为同功率三相的 √3 倍左右（`I ≈ P / (220·0.8·0.85)`），断路器 / 热继电器 / 线径相应放大一档，按铭牌核对。

> 待你提供卷帘 / 卷膜电机的**实际功率(kW)与铭牌额定电流**，可把上表精确到唯一一行的具体型号值。

## 十、安全与接地（两套方案通用）
1. **互锁必装**：正 / 反接触器机械互锁；三相再加电气互锁（辅助常闭串对方线圈）。
2. **限位双保险**：限位开关串入接触器线圈回路（硬件到位即断电）+ 接 ESP32（软件 `actuatorSafety` 到位停）。
3. **急停最高优先级**：直接切断接触器线圈（控制回路 / 变压器 220V 输出）电源。
4. **过载 / 过流**：热继电器（强电级）+ ACS712（ESP32 软件级）双重保护。
5. **缺相 / 相序保护**：三相方案必加（尤其三相三线无零线）。
6. **接地 PE**：电机外壳、控制箱、变压器、传感器屏蔽层均可靠接地；潮湿环境务必配漏电保护。
7. **本地手动**：手动按钮与继电器输出并联，断网 / MCU 故障时人工可控。
