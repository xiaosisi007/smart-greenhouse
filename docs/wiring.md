## 三、控制回路（关键）

```
ESP32 GPIO ──→ 继电器 ──→ 接触器线圈(A1/A2) ──→ 接触器主触点 ──→ 电机绕组
                                  │
                          【机械互锁】正转接触器 与 反转接触器 互锁
                                  │
限位开关 ── 串入接触器线圈回路（硬件级到位断电）+ ESP32 读取（软件级停机）双保险
本地手动按钮 ── 与继电器输出并联（断网/MCU 故障时人工可控）
```

要点：
1. **互锁必装**：卷帘正/反两个接触器、风口开/关两个接触器，分别机械互锁，杜绝同时吸合短路烧电机。
2. **限位双保险**：限位开关既串进接触器线圈回路（硬件到位即断电），又接 ESP32（软件 `actuatorSafety` 到位停）。
3. **过流保护**：ACS712 接 ESP32 ADC，运行电流超阈值（`CURTAIN_OVERCURRENT_A` / `VENT_OVERCURRENT_A`）判故障停机并告警，需远程或手动复位。
4. **断网兜底**：固件 `localFallback()` 在 MQTT 断开时按本地阈值自动控温/卷帘。
5. **急停**：急停按钮直接切断接触器线圈电源，优先级最高。

## 四、继电器电平

模组若为「低电平触发」（常见），保持 `pins.h` 中 `RELAY_ACTIVE_LOW 1`；高电平触发改为 `0`。

## 五、电流标定

ACS712-20A 灵敏度约 100mV/A、偏置 2.5V。`readCurrent()` 为简化算法，现场应空载测偏置电压并按实际灵敏度校正，必要时多次采样取 RMS。
