# 硬件采购清单（BOM，单棚）

> 配合 `docs/wiring.md` 接线说明使用。机器可读版见 `docs/bom.csv`（可直接导入 Excel/采购系统）。
> 参考价为 2025~2026 年淘宝/1688 常见价位（人民币），仅供预算估算，下单前以实际报价为准。
> 下单前先按 wiring.md「现场电压自检」确定走 220V（方案 A）还是 380V（方案 B），强电部分只买对应一套。
